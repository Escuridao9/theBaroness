# The Baroness

A fictional occult-inspired café website with a dark, atmospheric design inspired by the visual style of *Deadlock* and early 20th-century aesthetics.

The website presents **The Baroness**, an elegant and mysterious café where visitors can explore its story, menu, events, private lounges, and location.

## Overview

**The Baroness** was created as a web design project focused on building a complete website using semantic HTML and modern CSS.

The design combines:

* Dark, atmospheric visuals
* Occult-inspired elements
* Vintage café aesthetics
* Elegant typography
* Gold accents
* Responsive layouts
* CSS-only interactive elements

The goal was to create a website that feels like an actual establishment rather than a simple collection of web pages.

## Features

* **Hero section** introducing The Baroness
* **Lore section** describing the café and its atmosphere
* **Interactive menu** divided into categories
* **CSS-only menu modals** for additional item information
* **Events section** with multiple event panels
* **Private parlors** with their respective description
* **Reservation form**
* **Location and opening hours**
* Responsive navigation and layouts
* Custom typography and visual styling

## Technologies

The project was built using:

* **HTML5** — semantic page structure and content
* **CSS3** — layout, styling, animations, gradients, and responsive design
* **CSS Grid** — larger page layouts and structured sections
* **Flexbox** — navigation, cards, and smaller component layouts
* **CSS pseudo-classes** — interactive elements such as `:checked` states
* **Google Fonts / custom fonts** — typography and visual identity

### No JavaScript

This project intentionally does **not use JavaScript**.

Interactive components such as the menu item modals and event navigation are implemented using HTML and CSS, including hidden radio inputs, labels, and the `:checked` pseudo-class.

## Design

The visual identity of The Baroness is based around a dark and sophisticated colour palette, with black and dark grey backgrounds complemented by muted gold accents.

Typography is used to create contrast between:

* Decorative display headings
* Elegant serif text
* Clean, readable body text

The overall design aims to create the feeling of entering an old, mysterious but elegant café hidden within a larger city.

## Inspiration

The project takes visual inspiration from the atmosphere and art direction of **Deadlock**, particularly its darker occult and vintage-inspired aesthetic, while adapting those ideas into a fictional café setting. It also takes inspiration from a google stitch prompt that can be seen here:
